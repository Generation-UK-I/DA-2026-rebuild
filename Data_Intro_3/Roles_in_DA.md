## Common Roles Working with Data

Here are some of the important roles within the data domain that focus upon building systems for, gathering, and interpreting data...

>Note: These roles are not necessarily *set in stone*, some organisations interpret them differently, may not have people in each position, and the responsibilities may overlap and be distributed differently.

### Data Analyst

A Data Analyst leverage their available skills, tools, and methods to helps organisations understand their data and make informed decisions.

Typical Tasks include:

- Creating dashboards and reports
- Cleaning and analysing datasets
- Identifying trends and patterns
- Create visualisations representing datasets.
- Producing KPIs and business insights
- Answering business questions

Common tools and required skills include:

- Business understanding
- Communication and storytelling
- Data visualisation
- Statistics
- Excel
- SQL
- Power BI
- Tableau
- Python (including modules such as Numpy, Pandas, Matplotlib)

### Data Engineer

A Data Engineer builds and maintains the systems that move and store data, we generally refer to these systems as data pipelines. They make sure that the data is available and accessible, taking it from the data sources to the tools which are used to process and interpret it.

Typical Tasks:

- Building ETL/ELT pipelines
- Creating data warehouses and data lakes
- Integrating data from multiple systems
- Ensuring data quality and reliability
- Optimising data processing performance

Common Tools and required skills include:

- Software engineering
- Databases and SQL
- Data modelling
- Snowflake
- Python
- Databricks
- Cloud based data services and architecture

### Data Scientist

A Data Scientist uses statistics, analytical techniques, and machine learning (AI), to answer business questions, make predictions, and recommendations. They apply algorithms and processes to data sets of varying sizes, and use visualisation techniques to deliver and illustrate the results. Data scientists are sometimes seen as overlapping between DA and DE.

Typical Tasks:

- Building predictive models
- Machine learning
- Experimental design
- Forecasting based on historical analysis
- Customer segmentation
- AI and advanced analytics

Common Tools and required skills include:

- Python
- Jupyter Notebooks
- Scikit-learn
- TensorFlow
- PyTorch
- SQL

### Summary

|Role|Main Focus|Key Questions|
|---|---|---|
|Data Analyst|Understanding what happened|"What does the data tell us?"|
|Data Engineer|Building data infrastructure|"How do we collect and store data reliably?"|
|Data Scientist|Predicting and optimizing|"What will happen next, and how can we improve outcomes?"|

## Scenario Questions

Which role is best suited to the following tasks?

### Scenario 1: The Missing Sales Mystery

The CEO notices that sales have dropped by 12% over the last three months and wants to know why. The company already has clean, reliable sales data stored in a data warehouse.

The task is to:

- Examine historical sales data
- Identify trends and patterns
- Create charts and dashboards
- Present findings to management

<details><summary>Answer:</summary>Data Analyst:

The goal is to analyse existing data, identify trends, and communicate findings through reports and dashboards.</details>

---

### Scenario 2: Too Many Data Sources

A company stores customer information in a CRM system, order data in an e-commerce platform, and support tickets in a separate helpdesk system.

Management wants all data combined into a central data warehouse so reporting can be automated.

The task is to:

- Connect multiple systems
- Build automated data pipelines
- Clean and transform data
- Ensure data is reliable and available

<details><summary>Answer:</summary>Data Engineer

The focus is on building the infrastructure and pipelines that move and prepare data for analysis.</details>

---

### Scenario 3: Predicting Customer Churn

A telecommunications company wants to identify customers who are likely to cancel their contracts in the next six months.

The task is to:

- Analyse historical customer behaviour
- Build a machine learning model
- Predict future customer churn
- Recommend actions to reduce customer losses

<details><summary>Answer:</summary>Data Scientist

The objective is to use statistics and machine learning to make predictions about future outcomes.</details>
